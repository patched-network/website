## The longer bet

Skuilder aims to be a shared foundation for interactive tutoring. It would let course authors swap in their own teaching strategies, share and reuse course packages, and improve courses from evidence about how learners actually progress. We'd rather show that one piece at a time than claim it up front, so for now the work goes into making one course genuinely good.

LettersPractice is also how this work pays for itself. The hosted app at letterspractice.com is a paid product, and the code behind it is open for anyone to read, run and host themselves.
